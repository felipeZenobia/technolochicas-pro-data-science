# Technolochicas PRO - Data Science Portfolio 📊🚀

¡Bienvenida/o a mi repositorio de proyectos! Este espacio reúne las aplicaciones, análisis de datos y modelos desarrollados durante el curso de **Introducción a la Ciencia de Datos de Fundación Technolochicas PRO**.

## 🚀 Proyectos del Curso

A continuación se presentan los proyectos desarrollados a lo largo de la formación, ordenados por nivel de complejidad y área de aprendizaje:

### 📱 Fundamentos e Interacción Básica
* **HelloPurrStarter 🐱:** Aplicación con autenticación por contraseña que desbloquea la interfaz interactiva "Pet the cat".
* **Duck Sound App 🦆:** Manejo de eventos de clic en componentes de imagen para la reproducción de audio y recursos multimedia.
* **Mood Ring 🎭:** Contador de estados de ánimo (feliz, triste, enojado) mediante botones de selección visual e incremento de variables.

### 💾 Almacenamiento y Gestión de Datos
* **My ToDoList Starter 📝:** Gestor de tareas con operaciones CRUD completas (crear, leer, editar y eliminar actividades).
* **DIYBookClub 📚:** Aplicación para la creación, almacenamiento y consulta de reseñas literarias con persistencia de datos.
* **CloudDB Chat 💬:** Chat en tiempo real que utiliza CloudDB para la mensajería instantánea entre usuarios con registro de nombre de usuario.

### 📊 Análisis de Datos y Visualización
* **MoodTracker 📈:** Módulo de visualización de datos que representa frecuencias de estados de ánimo a través de gráficas de pastel y de barras.
* **Prediction Template (Lagos) 🌊:** Plantilla base de regresión y análisis de datos enfocada en el estudio de variables ambientales y modelado predictivo.
* **HealthSleep Analytics 📊💤 (Proyecto Final):** Aplicación avanzada de ciencia de datos que integra Google Sheets API, detección de anomalías en gráficas 2D, regresión lineal e inferencia con Inteligencia Artificial (API de Ollama).

### 🤖 Machine Learning e Inteligencia Artificial
* **App Classification 🧠:** Integración de un modelo de visión por computadora entrenado en **Teachable Machine** para la clasificación en tiempo real de rostros y objetos con cálculo de porcentajes de certeza.
